Pertanyaan Jawaban Kamu
Apa output program? 1020
Mengapa hasil tersebut terjadi? Karena nilai pada variabel a dan b diapit tanda kutip ("10" dan "20") sehingga terbaca sebagai tipe data String (teks). Operator + pada String melakukan penggabungan teks (concatenation), bukan penjumlahan matematika.
Apakah a dan b bertipe Number? Tidak. Keduanya bertipe data String.
Uji sekarang. Apakah prediksimu benar? Jelaskan. Benar. Saat dijalankan di Console (sridewi.js:4), output yang muncul adalah 1020 karena JavaScript menggabungkan teks "10" dan "20" menjadi satu string.

Temuan — Apa perbedaan String dan Number berdasarkan eksperimenmu?
String adalah tipe data untuk teks/karakter yang penulisannya wajib diapit tanda kutip ("..." atau '...'), sedangkan Number adalah tipe data angka yang ditulis langsung tanpa tanda kutip dan dapat dioperasikan secara matematis.

Bagian G • Aktivitas 5 (Tantangan)

Program Hitung Nilai

Soal Praktik: Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

Algoritma Saya:

  1. Menerima input nilai tugas, uts, dan uas dari pengguna menggunakan fungsi prompt().
  2. Mengonversi ketiga hasil input tersebut dari tipe data String menjadi tipe data angka menggunakan Number().
  3. Menghitung rata-rata nilai dengan rumus let rataRata = (tugas + uts + uas) / 3;.
  4. Menampilkan hasil nilai rata-rata ke layar Console menggunakan console.log().

Kode Program JavaScript:

let tugas = Number(prompt("Masukkan nilai Tugas: "));
let uts = Number(prompt("Masukkan nilai UTS: "));
let uas = Number(prompt("Masukkan nilai UAS: "));

let rataRata = (tugas + uts + uas) / 3;
console.log("Nilai rata-rata = " + rataRata);

Bagian H

Think Pair Share

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena fungsi prompt() selalu mengembalikan nilai bertipe String meskipun pengguna mengetikkan angka. Jika tidak dikonversi dengan Number(), operasi penjumlahan (+) akan menggabungkan teks, bukan menghitung nilai matematika.
Apa perbedaan "10" dengan 10? "10" adalah tipe data String (teks) karena diapit tanda kutip, sedangkan 10 adalah tipe data Number (angka asli) yang dapat dihitung secara aritmatika.
Apa yang terjadi jika lupa Number()? Pada operasi penjumlahan (+), angka akan digabung menyamping (contoh: "10" + "20" menjadi "1020"). Jika input berisi huruf lalu dihitung pada operator lain, hasilnya bisa menjadi NaN (Not-a-Number).
Pair: Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda? Secara konsep inti jawabannya sama, yaitu prompt() menghasilkan String dan perlu dikonversi menggunakan Number(). Perbedaan hanya terletak pada contoh kasus atau susunan kalimat penjelasan.
Share: Sampaikan satu temuan penting kepada kelas. Setiap input yang berasal dari prompt() di JavaScript selalu bertipe String, sehingga wajib dikonversi dengan Number() terlebih dahulu sebelum diproses dalam perhitungan matematika agar tidak terjadi bug penggabungan teks.
